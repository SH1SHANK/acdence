# GIT Helper Document for App Dev Project

> **Official Document Reference**: IIT Madras BS in Data Science and Applications — GIT Helper Document for Modern Application Development Projects (September 2026 Term).

---

## 1. Purpose & Overview

This document provides a step-by-step guide to:

1. Create a compliant GitHub account using your official IIT Madras BS student credentials.
2. Initialize a **private repository** to develop and maintain your project source code safely without accidental public exposure.
3. Add the official App Dev course ID as a collaborator so the academic team can verify development continuity, track milestones, and provide guidance.

---

## 2. Step 1: Create an Account on GitHub

1. Navigate to [GitHub](https://github.com) and select **Sign Up**.
2. **Email Address**: You **must** use your official IIT Madras BS degree student email address (`<student_id>@study.iitm.ac.in`).
3. **Password**: Create a secure password meeting GitHub requirements.
4. **Username Convention**: Your username must be your student roll number in lowercase format:
   - Example: `21f100XXXX`
   - _(If your student ID username is taken, choose an alternative username and record it in the registration form below)._
5. Complete verification and activate your account via email confirmation.

---

## 3. Step 2: Create a Private Repository

1. From your GitHub dashboard, select **Create repository** (or click the `+` icon $\to$ **New repository**).
2. **Repository Name**: Use a short, intuitive, hyphenated name reflecting your course and project statement:
   - For Trekking App V2: `tma-v2-project` or `mad2-trekking-app`
   - For Examination Portal V2: `emp-v2-project` or `mad2-exam-portal`
3. **Description**: Brief description (e.g., _"IITM BS MAD-II September 2026 Project"_).
4. **Privacy Setting (Mandatory)**: Select **Private**. It is strictly mandatory that your repository remains private to avoid plagiarism flags.
5. Check **Add a README file** to initialize repository with a root README.
6. Click **Create repository**.

## 4. Step 3: Add Course Team Collaborator

To enable the App Dev evaluation team to review commit history and track progress:

1. Open your newly created project repository on GitHub.
2. Click on the **Settings** tab in the top navigation bar.
3. In the left sidebar, select **Collaborators** under "Access".
4. Click the green **Add people** button under "Manage access".
5. Search for the official collaborator username:
   - **For MAD I**: `MADI-cs2003`
   - **For MAD II**: **`MADII-cs2006`**
6. Select **`MADII-cs2006`** and click **Add MADII-cs2006 to this repository**.
7. Confirm that the user shows up under "Pending Invite" or "Collaborators".

> **Dual Project Note**: Students enrolled concurrently in MAD-1 and MAD-2 projects must maintain **separate private repositories** and add `MADI-cs2003` to the MAD-1 repo and `MADII-cs2006` to the MAD-2 repo.
